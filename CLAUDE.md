# Projekt-Gedächtnis (`.vault/`, Obsidian)

- Zu Beginn jeder Session NUR `.vault/_index.md` lesen. Von dort nur die Themen-Notizen öffnen, die die Aufgabe braucht (`spiele/*` je Spiel, `systeme/*` je System, `decisions`, `gotchas`, `progress`). Neues Spiel/System → eigene kurze Notiz + Link im Index.
- Erst im Vault nachschauen, bevor du die Codebase durchsuchst. Bereits dokumentierte Dateien nicht erneut scannen, außer sie wurden geändert.
- Nach jeder abgeschlossenen Aufgabe (oder wenn der User "save" sagt) die betroffenen Notizen selbstständig aktualisieren.
- Notizen KURZ halten: Stichpunkte, Dateipfade + 1-Zeilen-Beschreibung, kein Code, keine Fließtexte. Veraltetes ersetzen statt anhängen. Notizen über ~80 Zeilen verdichten.
- Niemals Secrets, API-Keys oder Passwörter in den Vault schreiben.
